# ShopTracker-POS
A Python based management system using Tkinter, MySQL and Flask. The system is designed to help a retail business manage products. process sales, track stock sales and generate sales reports. 
Features: user authentication, product management, sales processing, inventory management, sales reporting, HTML receipts, REST API, relational database. database indexing. 
Technologies used: Python, Tkinter, MySQL, Flask, HTML

SETUP
1. Clone this repository: git clone https://github.com/vacatadaniella-spec/ShopTracker-POS.git
2. open the project folder: cd ShopTracker-POS
3. create and activate virtual environment. on windows: python -m venv .venv
                                                       .venv\Scripts\Activate.ps1
4. install the dependencies: pip install -r requirements.txt
You can run it by: python app.py or python main.py
